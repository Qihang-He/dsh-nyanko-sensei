# 角色校准记录 / Character calibration

这份文件记录**参考图 → 描述块**的校准过程。桌宠的还原度完全取决于
[`gen_art.py`](gen_art.py) 里的 `CHAR` 常量，而文字描述最危险的地方是它会**悄悄
偏离参照物**——所以每次修改都在这里留下"改了什么、为什么"。

参考图放在 `work/ref/`（**不入库**：那是动画原画截图，属于第三方版权素材，仅在本机
作为校对参照使用，不随包分发）。

---

## 第 1 版 —— 失败

第一版提示词只写了"圆滚滚的三花猫"，产出的是一个**通用招财猫摆件**：一个球、圆眼、
斑纹随机。用户判定"不是娘口三三"。根因是描述里**没有任何具名角色的可辨识特征**，
模型只能给一个泛化答案。

## 第 2 版 —— 依据参考图重写

从 `work/ref/` 的 5 张动画原画截图逐项读出以下事实。左列是**观察到的真实特征**，
右列是第 1 版的错误：

| # | 真实特征（参考图观察） | 第 1 版的错 |
| --- | --- | --- |
| 1 | 额头是**三段**：橘色块 → **细白中线** → 深灰块（放大 3 倍才看得清中线） | 左眼橘 + 右耳黑 |
| 2 | 眼睛是**细窄的弧线**（常画成闭眼/眯笑），不存在大圆金瞳 | 大圆金瞳大圆眼 |
| 3 | 体形：**蛋形**，头部窄、下腹与臀部最宽，整体**非常矮** | 正球体 |
| 4 | **戴深棕细项圈 + 金色小铃铛** | 完全没有 |
| 5 | 每侧脸颊有 **3 条红橙色斜线**（胡须记号） | 没有 |
| 6 | 嘴是**细弯线**，常呈波浪状"不满"表情 | 简单笑脸 |
| 7 | 耳朵**大而尖**，略外张 | 小圆耳 |
| 8 | 橘色覆盖**背与左侧**，深灰覆盖**背上方与右侧臀部**，正面胸腹纯白 | 斑块碎且随机 |
| 9 | 脸型**宽而扁**，不是圆脸 | 圆脸 |
| 10 | 前爪白色，**尾巴很短**（侧面图里只有一个贴身的圆凸起） | 长条纹尾 |

> **第 1 条是最关键的一条。** 它不是"两块斑"而是"两宽块夹一条细白缝"。这条白缝是
> 这只角色头部最强的辨识特征，也是第一版完全没抓住的东西——没有它，头就是一只普通
> 三花猫的头。

### 落到 `CHAR` 里的对应改动

- 体形描述从"perfectly round chubby"改成 **"an EGG — narrow at the shoulders,
  widest at the hips"**，并显式禁止球体（`NEVER a perfect sphere`）。
- 加入 **项圈与铃铛**（第 4 条）——这是最容易漏、但辨识度最高的配件之一。
- 斑纹描述改为**额头双斑**（橘 + 深灰），不再说"右耳黑"。
- 眼睛从"大而友好的金瞳"改成 **narrow almond-shaped, slant upward**，并说明表情
  是 sly / unimpressed 而非 wide-eyed cute。
- 加入**脸颊红斜线**与**白吻部**。
- 尾巴不再声明任何花纹，并显式禁止环纹（第 1 版在这里凭空加了狸猫环纹）。

### 仍然没有把握的部分

以下几条我无法从这 5 张图确证，属于"高置信但非确证"，**不写进 `CHAR`**，避免又引入
一个错误特征：

- 身体两侧斑块各自的精确归属（橘色偏左肩背还是偏右侧），参考图多为侧面/背面，左右
  关系会被视角混淆。
- 尾巴的准确长度与形状（参考图里尾巴都被身体挡住或裁掉）。
- 睁眼时瞳孔的确切形状（参考图基本是眯眼状态）。

**要闭合这几项，需要的是一张正面全身、四脚可见、尾巴可见的设定图。** 拿到之后补进
`work/ref/`，重新走一遍上面的校准表即可。

## 校准闭环怎么跑

描述块 → 出图 → **自己看** → 改描述。第二步之后必须真的看，否则就是在盲赌。

```bash
# 1. 出一版参考视图（先只出 front，便宜且够判断）
python tools/gen_art.py sheet --backend google

# 2. 用视觉模型把生成结果读一遍，和上面的校准表逐条对照
python tools/critique.py work/views/front.png

# 3. 按报告修改 gen_art.py 的 CHAR，删掉 front.* 重跑第 1 步
```

`tools/critique.py` 会把上表的 10 条特征作为检查项，让视觉模型逐条回答"符合 / 不符合 /
看不出来"，输出一份差距报告。**用它之前必须先自己看一眼**——模型会漏，而且它不知道
你真正在意哪一条。

## 一条必须说清楚的边界

参考图是**版权作品**，不会进入仓库，也不会被用作生成素材。本项目的做法是：用文字
描述把视觉特征**重新表达**一遍，再由图像模型**从零绘制**。这决定了还原度有上限——
它是一只"按特征重画"的同人形象，不是原画的像素级复制，也不应被当作官方素材使用。
见 [THIRD_PARTY_ASSETS.md](../THIRD_PARTY_ASSETS.md)。
